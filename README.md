# Advanced ATM Simulation - Java

## 📌 Project Overview

The Advanced ATM Simulation is a Java console-based application developed as part of the SkillNexis Java Programming Internship.

The project simulates basic ATM operations using Object-Oriented Programming, file handling, collections, and exception handling.

## ✨ Features

- PIN-based login
- Maximum 3 login attempts
- Check account balance
- Deposit money
- Withdraw money
- Transaction history
- Change PIN
- Display account details
- File-based data storage
- Exception handling for invalid input

## 🛠️ Technologies Used

- Java
- Object-Oriented Programming
- ArrayList
- File I/O
- Exception Handling
- Scanner

## 🧩 Java Concepts Demonstrated

### 1. Encapsulation

Account details such as account number, PIN, and balance are stored using private variables.

### 2. Collections

`ArrayList` is used to store transaction records.
